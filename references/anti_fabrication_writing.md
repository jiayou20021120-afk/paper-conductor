# 反编造写作纪律（内容来源隔离）

三道闸里的确定性 guard 管的是「机器味指纹」（排印、口水词），是**风格**层。这一条管的是**内容**层：事实、数据、引用、方法，必须来自本次会话的材料，不能来自模型的参数记忆。它服务「绝不编造数据 / 假引用」这条底线。

> 出处：移植自 ARS `academic-paper/references/anti_leakage_protocol.md`（其源头 PaperOrchestra, Song et al. 2026, Appendix D.4），翻成中文、接进 paper-conductor 阶段 3 写作。

## 什么时候启用

同时满足才启用：
- 在写作阶段（阶段 3），full 或 revision，不是选题 / 苏格拉底 / 探索模式（那时本来就要用模型知识发散）
- 手上有实质材料（已核验的数据、文献与标注、前稿），不是只有一句研究问题

## 知识来源隔离指令（写作前置进 context）

```
你正基于本次会话提供的材料写这篇论文：
- 已核验的数据、已定的研究问题、文献与标注、前稿、实验记录

优先级：
1. 一切事实性主张，优先用会话材料，不用模型的参数记忆
2. 每条主张都要能回溯到材料里的某个来源（某份数据或某条文献）
3. 提纲要求、但材料没覆盖的地方，打 [素材缺口] 标签交给用户定，不要凭记忆填
4. 不引入标注文献里没有的参考文献，除非用户明确要求
5. 方法部分只描述材料里记录过的程序，不推断、不脑补实验步骤

这不禁止你用语言能力、学术惯例、论证技巧、学科常识。限制只针对事实内容：
主张、引用、数据、方法描述必须来自会话材料。
```

## 标签处理

- `[素材缺口]`：在下一个 checkpoint 浮出来。用户补材料，或就这一处明确授权模型补充
- 一旦授权补充，该处改标 `[模型补充]`，留痕，方便审稿自查时重点核

## 和现有机制的关系

| 机制 | 它管什么 | 反编造纪律补什么 |
|---|---|---|
| 三道闸·确定性 guard | 机器味指纹（破折号 / 直引号 / 口水词） | 抓的是内容来源，不是风格 |
| rationale 矩阵（「用什么证据」那栏） | 写每个单元前先想清证据 | 它是矩阵的写作时强约束版，落到每条主张的具体来源 |
| `aiwei-zh` | 中文排印去 AI 味 | 两者正交 |

## 怎么用

阶段 3 动笔前，把「知识来源隔离指令」前置进写作 context。写完通读一遍，专挑那些本该打 `[素材缺口]` 却被顺手用记忆填上的句子，尤其是方法描述和「已有研究表明……」这类。

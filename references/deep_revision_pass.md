# 深修稿：工具过零之后的两步人工修（阶段 5→6 之间）

先立一条铁律：**`ai_tell_guard.py` 0 FAIL + `aiwei-zh` 双过 ≠ 去 AI 味完成。** 两个引擎都是词频与排印法：guard 对语义层的病只能给词命中的**线索**（那批 WARN），判定和修法都在本卡，要靠通读；"写得太多"这种更高一层的病，任何脚本都报不出来。跑完工具看见 PASS 就报"可定稿"，是最该戒的动作。深修稿分两步。

## 第一步：语义层三查（工具盲区）

| # | 病 | 怎么认出（可 grep 起步） | 修法 |
|---|---|---|---|
| 1 | **自夸式元评论**：给自己的发现贴"这正是全文最尖锐的张力 / 有锋芒的论断 / 值得点明" | grep：最尖锐 / 有锋芒 / 耐人寻味 / 值得点明 / 值得玩味 / 最有信息量 | 全删。让发现自己说话，评价交给读者 |
| 2 | **句式 tic**：这一 / 真正 / 恰恰 / 而是 密度过高，本身就是指纹 | guard 会报密度 WARN | 降到自然密度即可，不必清零（刻意清零反而是新指纹）|
| 3 | **说明文腔**：把本可直接断言的前提写成向读者讲解的因果论证 | grep：之所以…是因为 / 的价值在于 / 的合理性在于 / 的合法性来自 / 的意义在于 / 是为了避免 / 因为它说的是 / 换言之 / 需要强调的是 | 改直接断言，断言后直接上例子或数据。研究者口吻 = 断言 + 证据，不替读者把每步道理铺圆 |

第 3 条最易漏，专出没在引言、方法、阐释这些"讲自己为什么这么做"的段落。判据一句话：研究者阐释自己的研究，不需要什么都说得头头是道。

## 第二步：论证过剩收敛（第四轮修稿）

比 AI 味更高一层的病，会写的作者最难治：**舍不得删自己说对的话**。逐段只问一件事：

> **这段在增加发现，还是在增加自我辩护？是后者就删到只剩一句。**

编辑视角不看删了多少字，看这段读完读者信息有没有增加。从"我不是信号论"读到"我真的不是信号论"，信息增量为零，删。

三个具体动作：

1. **重复地图。** 列出每个核心命题 × 出现段落 × 次数。判刑规则：首次完整陈述保留；引言里提前宣布结果的删；讨论里把已证的东西重新证明一遍的删。读者不是不知道你要说什么，是已经知道太久了。
2. **隐喻收敛。** 全篇只留题目下注的那一套语义场，其余隐喻并入或删；同一比喻全篇最多一次，痕迹类比喻不超过两处。多套隐喻抢同一个意思，句句想当金句反而没有金句。
3. **"我不是什么"收敛。** 回应别家理论的自辩（不采用某框架、区别于某说法）每处压成一句，理由从简。但要分清两种东西：**对数据的诚实（反例、内生性、伪影）保留；对理论的自辩（我不是 X）收敛。** 少写我不是什么，多写我是什么。

成稿量级参考：这一轮通常只删 800 到 1200 字，但稿子会从"请相信我没说错"变成"这就是我的发现"。

## 怎么用

顺序：语义润色 → structural_ai_tells 结构扫 → readability_pass 负荷扫 → guard 脚本 → **本卡两步深修** → 交阶段 6。返修稿（尤其经历过多轮加固的）第二步是重点，越改越厚的稿子几乎必有论证过剩。
